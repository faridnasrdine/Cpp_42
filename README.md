> A series of C++ modules from the 42 Network curriculum — covering OOP, memory management, templates, STL, and more.

---

## 📦 Modules Overview

| Module | Topic |
|--------|-------|
| **CPP00** | Namespaces, classes, member functions, I/O streams |
| **CPP01** | Memory allocation, pointers, references, file streams |
| **CPP02** | Ad-hoc polymorphism, operator overloading, fixed-point numbers |
| **CPP03** | Inheritance |
| **CPP04** | Subtype polymorphism, abstract classes, interfaces |
| **CPP05** | Exceptions and error handling |
| **CPP06** | C++ type casting |
| **CPP07** | Templates |
| **CPP08** | Templated containers, iterators, algorithms |
| **CPP09** | STL containers in practice |

## ⚙️ Build & Run

Each module contains one or more exercises. To compile any exercise:

```bash
cd CPP0X/exXX
make
./executable
```

---

## 📌 Notes

- All modules follow the **C++98 standard**
- No STL allowed in early modules (CPP00–08 restrictions apply per exercise)
- Each module builds on the previous one
